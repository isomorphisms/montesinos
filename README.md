# Montesinos

Reading notes and implementation research on tessellations, orbifolds, Seifert manifolds, link theory, and geometric symmetry.

Start with [`books/README.md`](books/README.md). It covers Montesinos-Amilibia, Eisenbud–Neumann, Clay–Margalit, Saveliev, Conway–Burgiel–Goodman-Strauss, related public code, and Peter Scott’s eight 3-manifold geometries.

## Status

This repository currently contains references, source trails, and feature plans. It does not yet contain a finished tessellation, orbifold, or Seifert-manifold explorer.

Link to lawful public sources and preserve author and software credit. Do not add copyrighted books, papers, figures, or videos without clear permission.
